# 设计原则

## 色彩规范

### 主色调
- 主色: #1890FF (科技蓝)
- 主色悬停: #40A9FF
- 主色点击: #096DD9

### 辅助色
- 成功: #52C41A
- 警告: #FAAD14
- 错误: #FF4D4F
- 信息: #1890FF

### 中性色
- 标题文字: #262626 (二级标题)
- 正文文字: #595959
- 次要文字: #8C8C8C
- 禁用文字: #BFBFBF
- 边框: #D9D9D9
- 分割线: #F0F0F0
- 背景: #FAFAFA
- 页面背景: #F0F2F5

## 字体规范

### 字体族
- 优先使用系统字体: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif
- 代码字体: "SFMono-Regular", Consolas, "Liberation Mono", Menlo, monospace

### 字号层级
- 大标题: 24px/28px (h1)
- 标题: 20px/24px (h2)
- 小标题: 16px/20px (h3)
- 正文: 14px/18px
- 辅助文字: 12px/16px

### 字重
- 标题: 600 (Semibold)
- 正文: 400 (Regular)
- 强调: 500 (Medium)

## 间距规范

### 基础间距单位: 8px

- 页面内边距: 24px
- 卡片内边距: 16px
- 组件间距: 16px
- 元素间距: 8px
- 表单标签与输入框间距: 8px
- 表单字段间距: 24px
- 按钮左右内边距: 16px
- 按钮上下内边距: 4px

## 圆角规范

- 卡片圆角: 8px
- 按钮圆角: 4px
- 输入框圆角: 4px
- 弹窗圆角: 8px
- 标签圆角: 2px

## 阴影规范

- 卡片阴影: 0 2px 8px rgba(0,0,0,0.08)
- 下拉菜单阴影: 0 4px 12px rgba(0,0,0,0.12)
- 弹窗阴影: 0 8px 24px rgba(0,0,0,0.16)
